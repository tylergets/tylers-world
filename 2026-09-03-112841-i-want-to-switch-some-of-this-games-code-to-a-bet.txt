● Exploration is done, and it's a clear picture. The game is a Vite + Three.js
  app where the 3D world renders to a WebGL canvas and all UI is hand-rolled
  DOM: innerHTML templates plus targeted textContent updates, with version
  counters (Inventory.version, Dialogue.version, etc.) as the change-detection
  system. That version-counter pattern actually maps very cleanly onto React's
  useSyncExternalStore, so a migration is quite feasible — but a few parts
  should deliberately not become React (the WebGL canvas, the per-frame minimap
  canvases, and the title screen's pre-JS SVG animation).
